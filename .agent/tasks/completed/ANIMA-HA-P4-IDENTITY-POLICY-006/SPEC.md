# ANIMA-HA-P4-IDENTITY-POLICY-006

Implement the deterministic identity, action-risk, policy, confirmation, and
audit boundary required by Phase 4. OPA/Rego is a local replaceable evaluator;
ANIMA owns the contracts, evidence aggregation, risk taxonomy, policy input and
output, fail-closed behavior, audit, and runtime mutation restrictions.

Explicit exclusions: no Phase 5 plugins/MCP, Home Assistant, Luna, agent
cognition, action execution, verification, durable tasks, external tools, UI,
voice authentication, or biometric recognition.
