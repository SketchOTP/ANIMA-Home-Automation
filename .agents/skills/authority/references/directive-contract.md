# Architect → Codex Directive Contract

A valid substantial directive should contain:

# CODEX DIRECTIVE — <DIRECTIVE ID>

## Objective

Observable result required.

## Why this is next

Connection to project goal/stage/bottleneck/uncertainty.

## Known evidence

Relevant established facts and clearly labeled assumptions.

## Scope

Authorized inspection/change boundary.

## Do not change

Important exclusions and qualified/unrelated work to preserve.

## Required investigation

Technical facts Codex must establish before shared-behavior changes.

## External discovery

`REQUIRED` | `CONDITIONAL` | `NOT REQUIRED`, with trigger when conditional.

## Acceptance criteria

Objective success conditions.

## Required validation

Checks and minimum evidence level.

## Stop and return to Architect if

Strategic escalation conditions.

## Required project updates

`.agent`, Notion, and GitHub requirements.

## Required handoff

Canonical `CODEX RESULT`.

If a directive lacks a detail but the missing information can be safely established from current project/repository evidence without changing strategic intent, establish it. If the missing information materially affects scope, acceptance, safety, or strategic direction, return the ambiguity instead of guessing.
