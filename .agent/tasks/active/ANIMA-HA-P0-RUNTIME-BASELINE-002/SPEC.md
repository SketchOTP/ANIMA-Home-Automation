# ANIMA-HA-P0-RUNTIME-BASELINE-002

## Objective

Establish a minimal reproducible Python/Docker/PostgreSQL repository and engineering baseline without implementing household intelligence.

## Scope

Runtime selection, dependency qualification, package structure, configuration, structured logging, tests/lint/type checks, CI, migration mechanism, isolated database service, simulator entrypoint, restart/persistence evidence, documentation, and governed records.

## Exclusions

No Event Journal, Truth/State, graph, memory, policy, agent cognition, Home Assistant, NATS semantics, plugins/MCP, durable tasks, external tools, UI, voice, or product schema.

## Stop conditions

Escalate if the selected baseline lacks a credible ARM64 path, requires heavy premature infrastructure, or cannot be reproduced from a fresh checkout.
